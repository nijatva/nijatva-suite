What changed from the reference, and why

ReferenceVerdictChange
Droid-ify app detail Built Layout kept. Rating, reviews and download count removed — they need a server that logs users. Replaced with facts we can prove offline: sha256, signer fingerprint, minSdk, permissions.
Exodus privacy score 3/10 Rewritten No third-party score. no-gms-check writes the report at build time — banned groups found, INTERNET yes/no, dependency count — and the index carries it. Same idea, verifiable source.
F-Droid 5-tab bottom bar Trimmed Three tabs: Explore · Installed · Updates. "Nearby" waits for the Wi-Fi Direct transfer feature, which does not exist yet.
Updates list with debug builds Gated Debug-signed APKs and latest tags are refused by the index, so the row says Debug and offers nothing. That is the honest state of 10 of 11 released apps today.
Neo Store vertical category lettering Dropped Vertical text breaks at 200% font scale and in RTL. Normal sticky header instead.
Privacy dashboard, 24-hour access log Not built Per-app camera/mic history is OS data. Nijatva shows requested permissions and labels them as such — see the risk donut.
Nothing-style gradient Spaces cards Scoped HeroCard gradients allowed only in Launcher, WorkSpace and the store banner. Utility apps stay flat on AMOLED.
